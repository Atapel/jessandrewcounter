# jessandrewcounter

A joke "Days Since Andrew & jessunchik Had Good Vibes" counter, styled like the
classic factory "XXX days without an accident" sign.

Open `index.html` in a browser, or host the folder as a static site (GitHub Pages,
Netlify, etc.).

- Last incident is stored in `localStorage`; defaults to Mon May 4, 2026.
- Click **Report New Incident** to reset — password gated.
- All-time record is tracked locally too.
